# Tutorials

## Create A Simple Review Process

1. Open the operator workspace at `/ui`.
2. Ask the assistant to create a review process.
3. Confirm the workflow appears in the Process Editor.
4. Review validation diagnostics.
5. Deploy the workflow when it is ready.
6. Run a case and confirm that the first work item appears in the Work Items
   view.

## Run A Case

1. Open the deployed workflow.
2. Use the run control to start a case.
3. Monitor the case in the operator views.
4. Complete the assigned work item.
5. Confirm the case advances to the next event or terminal state.

## Connect An Information System

1. Define the information-system binding in the workflow.
2. Configure the connector in a safe environment.
3. Validate adapter and trigger readiness.
4. Deploy only after validation produces a non-blocking receipt.

Public tutorials avoid private connector endpoints, production chat ids, tokens,
and operational logs. Use repository runbooks for environment-specific setup.
